# Nawrez Mechraoui — site

Vite + TypeScript, Three.js (WebGL), GSAP (ScrollTrigger, SplitText) and Lenis.

```
npm install
npm run dev       # http://localhost:5173
npm run build
```

## Photos

Every image slot is a placeholder generated by `scripts/placeholders.mjs`. To use real photos,
drop them into `assets-src/raw/` with the same names (jpg/png/webp), then run `npm run images`:

| file        | where                                   |
|-------------|-----------------------------------------|
| `portrait`  | hero scanline portrait (bright face on a darker background reads best) |
| `diwan`, `hiwar`, `verites`, `mou7a9e9` | antenna cards |
| `studio-1` … `studio-4` | "Derrière le micro" steps (Préparer, Interroger, En direct, Produire) |
